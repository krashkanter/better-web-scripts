# Agent instructions

- Do not add `Co-Authored-By` trailers or any other AI attribution to commit messages, pull requests, or files.
- Userscripts live at the repo root as `*.user.js`, each with `@downloadURL`/`@updateURL` pointing at `main`. Bump `@version` when you change a script so Tampermonkey picks up the update.
- Setting up YouTube Full Buffer for a user: follow "Adding the flags (instructions for agents)" in README.md.
